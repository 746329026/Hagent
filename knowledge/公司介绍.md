公司成立于二零零八年三月，总部位于浙江省杭州市滨江区，是一家专注于企业级软件服务的技术公司。创始团队来自国内知名互联网企业，在分布式系统与企业应用领域有十余年积累。

公司主营业务包括三块：一是企业协同办公平台，为中型以上企业提供流程审批、文档协作与知识管理能力；二是数据中台解决方案，帮助客户打通内部数据孤岛、建立统一的数据资产目录；三是面向特定行业的定制化软件开发，目前覆盖制造、医疗与教育三个行业。

截至二零二四年，公司共有员工三百二十七人，其中研发人员占比百分之六十二。在上海、深圳、成都设有三个分支机构。公司已通过 ISO27001 信息安全管理体系认证与 CMMI3 级评估。

公司的主要客户包括三十余家上市公司与多家大型国有企业。二零二三年营业收入为四点七亿元，近三年复合增长率为百分之二十八。公司于二零二一年完成 C 轮融资，投资方包括国内两家知名产业基金。

公司的技术栈以 Java 生态为主，后端服务基于 Spring 框架构建，数据存储采用 MySQL 与 Redis 组合，检索能力基于 Elasticsearch。前端使用 Vue 与 React 双技术栈，移动端同时提供 iOS 与 Android 原生应用。

企业文化强调"工程师文化"与"客户价值"。公司实行扁平化管理，全员可参与技术方案评审。每周三下午为固定的技术分享时间，任何员工都可申请主讲。公司设有内部开源机制，员工可将通用组件提交至内部组件库供全公司复用。
